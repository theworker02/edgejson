# edgejson

Edge timestamps and json durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/edgejson/

## Install / run

```bash
git clone https://github.com/theworker02/edgejson.git
cd edgejson
node src/cli.js
node --test
```
